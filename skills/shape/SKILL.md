# Shape — from rough idea to one-page brief

The user describes a rough idea. If the user didn't say what it's about, ask them first.

**Do NOT write the brief yet.** First, interview the user. Ask 3–6 sharp questions, **one at a time**, to uncover:
- the core problem, and who actually has it
- the target user and the context where they'd use this
- what success looks like (the outcome, not the feature)
- real constraints (time, budget, tech, regulatory)
- why now, and why them

Wait for each answer before asking the next question. Once you have enough, produce a one-page brief:

**Problem · Target user · Proposed solution (1 short paragraph) · Why now · Success metrics · Biggest risks · Open questions**

Keep it to one page. Explicitly flag anything the user stayed vague about.
