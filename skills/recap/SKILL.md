# Recap — where are we?

Give a concise recap of the current session:
- **Goal:** what we set out to do.
- **Done:** what's completed, with the key files or commands involved.
- **Next:** what's still open or worth doing next.

Keep it short and scannable. If the session is worth remembering, suggest running `session-wrap` to save it in the vault.
