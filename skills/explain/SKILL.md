# Explain — simply, with an example and an analogy

Explain the concept, term or file the user gives. If the user didn't say what it's about, ask them first. If it's a file, read it first.

Structure the answer:
1. **What it is:** one or two plain sentences.
2. **Why it matters:** when you'd actually use it.
3. **A concrete example:** minimal and real.
4. **An analogy:** to something everyday.

Assume the user is smart but new to the topic. Keep it tight, no padding.
